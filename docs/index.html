Everything you need

From container lifecycle to AI inference monitoring, all in one terminal window

📊

Real-time Metrics

CPU%, memory, network RX/TX, disk I/O — all with sparkline history. Per-CPU bars when CPU is pinned to specific cores.

🔬

Syscall Tracing

bpftrace-powered syscall monitoring per container. 7 family categories, top-12 table, activity sparkline, and auto-generate minimal OCI seccomp JSON.

🔐

HTTPS Interception

Transparent MITM proxy via nftables REDIRECT. HTTP/2 aware. One key to set up: auto-injects CA cert, configures NODE_EXTRA_CA_CERTS. Works with Node.js, Python, curl.

💰

Inference Stats

Track AI model API usage: RPM, RPH, TPM, tokens in/out, and cost estimation for 27+ models (GPT/Claude/Gemini). Per-minute sparklines and session breakdown.

🔀

Inference Routing

Redirect AI API calls to alternative backends. Route OpenAI → local Ollama, Copilot → NVIDIA Endpoint — transparent to the application.

🛡️

Security Policy Engine

Seccomp profile management, AppArmor, nftables egress control, DNS monitor. Generate seccomp profiles from observed syscall data. YAML export/import.

Get started in seconds

Single binary — copy to any Linux host and run

1

Download the binary

Grab the latest release for your architecture from GitHub Releases.

curl -Lo cella https://github.com/fourdollars/cella/releases/download/latest/cella_linux_amd64 chmod +x cella
2

Run (requires LXD or Docker)

Add yourself to the lxd group, or run with sudo.

sudo ./cella
3

Enable HTTPS interception (optional)

Press A for Audit panel, then p on any container to intercept its traffic.

# In cella TUI: # A → opens Audit panel # p → sets up nftables REDIRECT + injects CA cert into container # Y/y/n → approve/deny each domain as it appears
4

Build from source

Requires Go 1.20+

git clone https://github.com/fourdollars/cella cd cella go build -o cella ./cmd/main.go
