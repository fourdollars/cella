📚 Complete Key Binding Reference

All keyboard shortcuts available in cella, organized by context.

Global (available from any panel)

KeyAction
↑ / kMove selection up
↓ / jMove selection down
PgUpScroll up half page
PgDnScroll down half page
q / Ctrl+CQuit cella
?Toggle help overlay
/Search / filter
Ctrl+LForce refresh
EscReturn to previous panel / close overlay

Container Operations

KeyAction
sStart selected container
xStop selected container
pPause selected container (or setup proxy in Audit panel)
eExec — interactive shell in container
+Create new container (wizard)
dDelete selected container

Panel Navigation

KeyPanel
gDashboard (default view)
lLogs — streaming container logs
wNetwork — RX/TX, ports, connections
rResources — CPU/memory limits, per-CPU bars
nSnapshots — create, restore, clone
tSyscall Trace — bpftrace passive monitoring
GSeccomp Generator — generate OCI seccomp JSON
PPolicy — seccomp + AppArmor + egress overview
ZToggle syscall blocking (LXD BPF deny)
DDNS Monitor — DNS traffic + allow/deny
AAPI Audit — HTTP proxy log + approvals
MInference Stats — RPM/TPM/cost per model
RInference Routing — redirect AI APIs
VEvents — LXD event log
EExport — container config to JSON
IImport — apply config from JSON
TStop syscall tracing
