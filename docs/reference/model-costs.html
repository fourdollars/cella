Fuzzy Matching

cella uses fuzzy matching on model names. If the intercepted model string contains a known key (case-insensitive), the corresponding pricing is applied. For example, github-copilot/gpt-4o matches the gpt-4o pricing entry.

Unknown Models

If a model isn't recognized, cella still tracks token counts and request rates — it just reports $0.00 for cost. You can identify these in the Inference Stats panel (M) and add pricing if needed.

💡 Pricing data is compiled into the binary in internal/proxy/inference_stats.go. To update, modify the knownPricing map and rebuild.
